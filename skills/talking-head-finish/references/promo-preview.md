# 宣传式效果预览

安装演示与用户整片是两种交付。`studio.py demo` 创建 36 秒公开效果样片：品牌开场 → 四种空间 → 无手纸艺两种演绎 → 珍珠白与夜紫银装置 → 收尾。只有代码动画、背景和短 SFX，没有作者的私人人像或旁白。

## 用户本期预览

从实际编码的成片/工作预览中选取完整语义小段，配短品牌开场和收尾，做约 20–40 秒宣传样片；不替换或压缩整片时间线。先完成若干有代表性的镜头，再完成全片；当实际源片覆盖全部选段后可用下面的脚本。

```text
python scripts/showreel.py --project <已渲染本期工程> --out-project <新宣传工程>
python scripts/studio.py setup --project <新宣传工程>
python scripts/studio.py render --project <新宣传工程>
```

可用 `--source <实际已编码的工作预览>`，但源片必须覆盖 plan 中对应时码。showreel.py 按原 SRT 句子边界选择 4 段不同机制，保留原速、原声和片段已有 SFX；只在开场收尾新增短音效，默认无 BGM。同一主题的第一版需要更精确的节选时，Agent 修改镜头表后复核，不为了凑时长截断一句话或冻结画面。

每个镜头只突出一个卖点。重点 100–150px，辅助 40–72px；大字先出现并收稳，材质/空间/镜头关系变化，少量灯光和惯性完成衔接。不要以花哨转场盖住信息，不做全片黑底文字卡。

显示实际用户片段时保留真实身份和原声音，不伪造“原来很差”的对比，不使用第三方创作者视频素材。片头可以换成用户自己的品牌，不能暗示其是作者本人。公开上传私人预览另需用户明确授权；制作不等于发布。

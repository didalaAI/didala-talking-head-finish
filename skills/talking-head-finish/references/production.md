# V4机制的使用与品质

先读用户本期原片/SRT。每镜写出文案锚点、对象、动作、变化结果、合适机制及阅读停留。选择机制的依据是它是否解释清楚本句，不是填满所有时长。

## 本版实际代码

- `assets/template/src/Human.tsx`：V4旁侧字级和大字进入/收稳，文字改为计划参数。真人来自用户视频；动态穿身由合成时的人物mask恢复实现。
- `SceneKit.tsx`：纸面/蓝灰/淡绿实体工作区、字体、道具、浏览器框、机械读取窗口与时钟。
- `ExplainScenes.tsx`：具体称呼问答、三轮请求装配、前文重读、内容堆积、有限范围和回顾。
- `WorkScenes.tsx`：要求遗漏、处理等待、负担、模型容量、交接文档、继续工作、摘要和约束遗漏。预览可接用户自己的视频；默认是明确标注的动态代码示意，不冒充真人或真实录屏。
- `ScreenScene.tsx`：从完整原图连续推近测量过的focus矩形，保留全图定位和软件身份。不能直接拿模糊小裁图放大。

40段索引记录原案例用途，其中9段人物字效可用参数化文字实现，23段MG对应实际机制代码，8段H3保存为镜头配方与生成接口。没有把作者生成视频当成公共素材打包。新题材修改或新增对应组件及Remade路由，不照搬原案例台词或固定镜头数量。

## 必须维持的感觉

大标题与解释有清楚主次，暖白/淡紫或低饱和实体材质，少量重点色；词组自然排字。动画应真的完成拿取、装配、读取、变化、交接等动作，长说明分阶段发展。全文结合不同MG、真实截图和合适的H3，避免黑PPT、空画框或同一柜子/机器人反复改字。

Vox需要丰富的纸张层次、道具、空间和动作，前景/中景/背景形成运镜；它只是一种表达。新的片段不应只剩“静图推近”。同一段故事保持角色与道具，下一镜参考实际上一镜尾帧。准确中文尽量在后期字层解决。

人物出镜保持一句或一个论点的完整讲述。全屏动画之间可直接衔接，不在切点透明淡出露出真人。穿身有动态遮挡；未取得mask时改为不穿身的构图，不把缺失技术伪装为已完成。

原声1.0、原SRT内容与时码保持。声音按本期动作合成，安静段保留，无BGM。视频原生规格和最终导出规格分开写；缓存与检查绑定当前文件哈希。原速观看、关键动作/接点帧和音频检查不能被脚本退出0代替；没有人工试听就如实标记未试听。

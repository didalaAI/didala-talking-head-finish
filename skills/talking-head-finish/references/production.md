# 已确认效果与制作标准

以 approved-effects.json 为唯一默认选择清单。先前 V4 是品质参照，不是默认全量效果库；旧 teal 工作台、文档卡 PPT、带手纸艺、石墨橙已退出公开分发。

23 项中：真人旁字/闪身机制 9 项、H3 场景配方 8 项、MG 6 项。P2-Capacity/P2-Packet 常用；W1 和 V1 的 Capacity/Packet 为偶尔。不把“常用”解释成每个主题都要出现，也不连续重复装置。

六项 MG 的实际源码在 assets/template/src/ApprovedMG.tsx 与 CompareKit.tsx。P2 是滚轴/纸夹/折页封装；W1 是珍珠白左右展陈；V1 是夜紫银中心汇流。SceneContext 接收本期标题、重点词与具体对象；必须检查该机制是否适合本句内容。默认的上下文窗口问答仅用于演示。

真人字效在 Human.tsx。背景 → 大字 → 动态人物前景，普通字幕最后出现；侧字留出本期人物和手势区域。白/浅紫为基础字，单一强调色突出重点。整词进入、放大、错位、遮挡或收稳服务于含义，避免将“上下文窗口”拆成不自然碎字。

全屏场景应是一个具体事件的进展，讲到累积就增加、讲到丢失就真的缺一项、讲到交接就转移物件，不能只出现标签。保持景别、素材和材质变化；保留实际动作轨迹、建立镜头与阅读停留。

生成配方是可改编的动作与连续性标准，不包含私人成片或首帧。适配用户可用后端后必须真生成、真审片；不同 Agent 的审美和生成服务会影响结果，不能承诺一份提示词精确复刻视频。

交付前核验实际 MP4：关键字可读、字体无缺字/裁切、人物边缘自然、入出场完整、无静图冒充长动画、字幕和原声未改速、无音效重复、无多余片尾冻结。背景与抠像需依 matting.md 复核，宣传样片需依 promo-preview.md。


真人九项的实际编排示例见 [human-choreography.json](human-choreography.json)。`beats` 保存分阶段旁字/穿身/CTA换词，`tags` 保存逐条要点与可选本期图标，`meter` 保存进度与可选真实数字；不再把全部真人段简化成同一种旁字。按本期 SRT 重新定时，不能直接照搬例句、呼吁动作或数字。

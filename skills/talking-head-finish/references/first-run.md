# 首次制作与生成后端选择

用户只需调用Skill并提供已剪视频和SRT。以下由Agent执行，除关键输入、实际权限或后端选择外，不反复让用户操作终端。每期用新项目，不覆盖原片。

## 开始制作

1. 检查输入和时间对应，读production.md并查看人物、动作和背景；执行`studio.py doctor`。基础缺项按权限补齐，H3缺项不阻止分析文案、准备分镜、字幕和真人字效。
2. 执行 `python scripts/capabilities.py inspect`。默认只读`127.0.0.1:8188/object_info`，核对所需节点/模型选项；已有配置用`--config <配置JSON>`。不扫描磁盘/其他端口，不上传素材，不提交生成，不展示密钥。只有Comfy或显卡不代表H3可用。
3. `compatible_metadata`只表示服务声明了所需节点与模型选项，仍需验证实际加载、显存与动作。`not_detected`不能说成“没安装H3”；`needs_configuration`应解释缺节点/模型；`needs_cloud_verification`不等于云端跑通。
4. 已指定本地H3且可用，或调用本Skill时已有可用本地H3，就沿用并先验证短镜头，不重复问；首次说明本地计算。失败时保留错误和其他制作进度，回到下面选择，不反复重试或悄悄改用付费服务。
5. 执行 `studio.py init --video <MP4> --srt <SRT> --project <空目录>`。它保留原字幕并写未选的`production-choice.json`。选定后记录本期方式，再完成分镜；记录不代表云端权限或生成质量已验证。

## 没有可用H3时，问一次

建议：“当前没有检测到可用的H3生成服务。这期你希望怎样继续？”没有某项工具时说明需先配置，不假称已可用。

| 选项 | 会得到什么 | mode |
| --- | --- | --- |
| 动态MG＋现有素材完成整片 | 保留真人字效、字幕和音效；丰富语义MG、合法可用视频/截图与运镜，无需H3 | motion |
| 接入自己的云端生成服务 | 用户选服务、确认费用和上传范围，Agent适配后生成 | cloud |
| 用当前Agent已有的其他视频模型 | 检查真实工具、授权与费用，适配动作；不同后端不保证与H3输出相同 | other |
| 先做其他部分，稍后补生成动画 | 完成分镜、真人字效、MG、字幕和声音，列缺少镜头与提示词，交付工程/工作预览 | defer |

沿用已有明确选择。未回复时继续不依赖选择的部分，不以等待时长作为同意，不默认MG或云生成。不要求先装GPU、大模型或陌生付费插件才开始全部工作。

选择后执行（相对Skill目录）：

```text
python scripts/capabilities.py choose --project <项目目录> --mode motion --note "用户选择动态MG和现有素材完成"
```

其他方式改为local-h3/cloud/other/defer。用户明确改变时，用`change --project <项目目录> --mode <新方式> --note <用户新选择>`保留历史；失败不悄悄切换。密钥只放环境变量，不写进note、截图或SRT。

## 各种方式的质量要求

- **motion**：每个论点设计“对象→行为→结果”。实体工作区、纸艺拼贴/多层视差、操作录屏、不同MG机制交替；动作和运镜帮助理解。需要新对象就写新组件，不照搬案例改字；交接/删除/累积不能变成长停帧，不全片同款卡片横移，不声称生成了H3。
- **local-h3**：按generation.md和镜头配方制作，实际生成并审片。用户有效配置优先，不要求模型文件名与作者示例相同；用实际配置检测。
- **cloud/other**：确认服务、素材去向与费用后提交。自带适配器为ComfyUI/Comfy Cloud，其他服务用Agent真实工具或另行实现适配器。失败续跑原收据，保留其他进度并由用户选择下一步。
- **defer**：写`missing-shots.json`，含SRT范围、语义变化、首帧/动作提示词、时长、原因与接入方式。预览文件/报告标明未完成，不把占位、冻结和文字页当最终成片。`render`会阻止未选或defer项目导出final；预览可用Remotion Studio，或项目render.cjs导出明确命名的工作预览。

按production.md审核小样与完整动作、字效和衔接。保留原声原速、原SRT和可编辑工程；技术检查、实际观看、人工试听分别记录。安装Skill或选定模型不保证首版达到作者审美，须依据当前编码继续修订。

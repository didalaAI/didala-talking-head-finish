# 0.1.2-preview 发行说明

本次实现“发仓库链接安装→发送MP4与SRT制作”的Agent使用流程：新增根目录AGENTS入口、安装约定、完整资源安装收据与重复安装校验、只读H3元数据检测，以及每期明确制作方式。Skill安装和基础运行环境检查分别报告，H3不列为基础必装项。

没有可用H3时由粉丝自己选择动态MG与现有素材、自己的云服务、Agent已有的其他视频模型，或先做其他部分稍后补动画；不自动降级、不默认产生云费用。选择保存在production-choice.json，改变方式保留历史；未选或defer项目不能通过final渲染校验。具体执行见[Agent安装约定](INSTALL-FOR-AGENTS.md)与[首次制作](../skills/talking-head-finish/references/first-run.md)。

基础doctor缺项时返回2；有GPU、运行了Comfy或有云密钥不等于实际生成成功。检测仅做只读元数据/本机配置判断，H3仍需短镜头实测。基础渲染、字体、V4字效和MG代码保留，版本号更新为0.1.2。共27项单元与协议测试通过；Windows CI改为从安装副本安装依赖并渲染24秒演示。客户端真实试用与可选GPU生成状态仍按VALIDATION如实列出。

## 先前版本

本次补丁统一GitHub新用户名didalaAI及当前文档链接，并增加WorkBuddy、豆包工作的轻量工程引导导出器和运行边界说明。两个宿主尚未端到端验证，不标为“已实现同效果一键成片”。渲染组件、字体和锁定的依赖版本保持原来的实际实现；运行时包自身版本更新为0.1.1。

历史0.1.0/0.1.1-preview的提交、标签和附件保留作为原始记录，不强改已发布文件哈希；当前下载请使用0.1.2-preview。

本版把“只有规则文字”的Skill变成自包含的机制代码、运行脚本与镜头配方。主入口保留V4的人物旁字、进入后收稳的大字、实体MG、动态人物遮挡接口、原截图推近和可选H3；并未把整片统一换成Vox。

包含40段机制索引、23段MG实现、8组H3配方及实际API工作流。人像、原录音、聊天截图、旧生成片、模型、GPU环境和密钥不在公开包内。新文案仍需Agent做逐句语义设计，不能保证靠同一个随机提示词复制出逐像素相同的H3片段。

## 给粉丝的第一步

1. 给支持本地技能与执行工具的Agent发仓库链接，说“帮我安装这个Skill”。
2. Agent按安装约定安装完整资源、检查并准备基础环境、实际运行演示；不能只复述终端命令。
3. 提供自己的已剪MP4与SRT，说“按这个Skill剪辑好口播视频”。
4. 已有可用本地H3就使用；没有则由用户选择制作方式，Agent保留选择并按文意制作。
5. 交付成片、原SRT、可编辑工程与检查记录；选择稍后补动画则交付明确标记未完成的工程和缺镜头清单。

## GitHub发布步骤

1. 在自己的账号或组织新建公开仓库`didala-talking-head-finish`；不要用个人私用Skill目录直接创建仓库。
2. 上传本公开源码包中的文件；README、LICENSE与第三方说明一起保留。
3. 执行仓库自带`python scripts/release.py audit`与单元测试；GitHub Actions会重复测试，并在Windows检查Node类型和完整demo渲染。
4. 创建`v0.1.2-preview`预发行版，把源码ZIP、24秒基础demo、验证记录和SHA256SUMS作为Release附件。大视频和模型不放进Git历史。
5. 抖音简介放仓库链接；置顶说明“Windows预览版，基础MG可跑，H3需自备后端，可能产生服务费用”。先邀请少量粉丝在不同机器试用，收集日志时删去本机路径和账号数据。
6. 本地H3、真实云生成、GPU后期和至少一台其他机器的完整验证完成后，再发布稳定版；新增环境实测写入VALIDATION，不用旧片成功记录代替。

本版先提供GitHub源码和本地Skill安装。后续若希望粉丝通过插件目录安装，可按[官方插件封装文档](https://developers.openai.com/plugins/build/plugins)包装同一技能及安装指引；这不免除本地FFmpeg/Node等执行依赖，不把“插件装上了”当作GPU环境已经就绪。

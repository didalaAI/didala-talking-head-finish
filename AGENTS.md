# Agent entry points

For a repository-link installation request, read the [Agent installation
contract](docs/INSTALL-FOR-AGENTS.md) and install the complete
`skills/talking-head-finish` folder using the current host's supported mechanism.
Do not stop after quoting manual commands if you can perform the work.

For video/SRT production, read the installed SKILL.md and references/first-run.md.
H3 is optional: preserve the user's choice; when no compatible backend is
available, ask for their preferred production mode.

For development run `python -m unittest discover -s tests -v` and
`python scripts/release.py audit`. Preserve complete fonts, licenses and original
audio/speed. Do not import the author's private media, environment or credentials.
